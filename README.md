# Robin Overtime (罗宾加班)

星露谷物语 1.6 Mod:罗宾干活太慢,右键找她,让她加班!

## 功能

**农场建筑(新建/升级)**:
- 在罗宾处**新建/升级建筑**付款后,回到罗宾店里,**原版的"建造中"对话会被替换成加班问题框**直接弹出
- 选「不用了」→ 接着弹出罗宾原版的"建造中"对话,然后你可以在工地右键罗宾再次询问

**房屋升级(罗宾柜台对话买的那种)**:
- 房屋升级进行中时(罗宾在农舍门口敲锤子的那几天),右键罗宾同样弹加班询问
- 费用按当前这级升级的原价算:第 1 次 1 万、第 2 次 6.5 万、第 3 次 10 万,同样 × 加班费倍数
- 房屋升级不走商店菜单,所以付款时不会弹加班框——等罗宾到工地开工后右键她即可,不会打断柜台对话

**右键罗宾**(任意时间/地点,她人在店里或工地都行):
- 有正在施工/升级的建筑或房屋升级时,右键罗宾优先弹:
  「XX 还没建完。赶着用吗?加 Xg,我连夜赶工,工期减半——只剩最后一天的话,今天就能交工。」
- 选「行,那就拜托你了」→ **剩余工期减半**;剩最后一天 → **立即完工**(走原版完工流程)
- 选「不用了」→ 回到罗宾原版对话(不影响好感/剧情)
- 多个项目同时在建(建筑 + 房屋升级)时**一次只问一个**:建筑优先,房屋升级其次,再右键一次问下一个
- 有在建项目时**加班框绝对优先**:右键罗宾必先弹加班询问,不会先被原版对话顶掉
- 无在建项目 → 原版对话,行为完全不变

**费用**:加班费 = 建筑(或升级项、房屋升级)费用 × 2(可配置 1.0~3.0)

**联机**:主机弹窗操作;付款成功后广播给客机(双方都装本 mod),客机弹同样的 HUD 提示。

## 配置(需 GenericModConfigMenu)

游戏内 ESC → 齿轮 → "罗宾加班"页:

- 右键罗宾补款(开/关)
- 加班费倍数(1.0~3.0,默认 2.0)

## 安装

1. 点右上角 **Code → Download ZIP** 下载本仓库
2. 解压后把 `RobinOvertime` 文件夹放进 `Stardew Valley\Mods\`(确认里面有 `RobinOvertime.dll` 和 `manifest.json`)
3. 需要 [SMAPI](https://smapi.io/)(4.0+) 和 [GenericModConfigMenu](https://www.nexusmods.com/stardewvalley/mods/5098)(可选,用于配置页)

## 兼容性

- 单人/联机(主机操作,客机只收 HUD 提示)
- 支持主农场 + 姜岛农场建筑;房屋升级只针对主机(原版也只有主机能买房屋升级)
- 只处理罗宾(Builder=Robin)建造的建筑,不影响法师魔法建筑
- 送礼优先:手持物品时右键罗宾正常送礼,不弹加班框
