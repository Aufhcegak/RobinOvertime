# Robin Overtime (罗宾加班)

星露谷物语 1.6 Mod:罗宾干活太慢,让她加班!两条入口,均可关可调。

## 功能

**自动弹窗**(建造后回到农场时触发):
- 在罗宾处**新建建筑**或**升级建筑**后,回到农场(主农场/姜岛)自动弹出:
  「XX 正在施工。赶工期吗?加班费 Xg,付了的话明天一早就能建完!」
- 付钱 → **第二天一早完工**(跳过原版工期);不付 → 按原版工期施工
- 剩最后一天的不问(反正明天完工,不让玩家白花钱)

**右键罗宾补款**(任何地点右键罗宾):
- 优先问:「哟,来看进度啊?要加个班不?Xg,工期直接砍半;只剩最后一天的话,付了今天就完工!」
- 付钱 → **剩余工期减半**;剩最后一天 → **立即完工**
- 选"不用了" → 回到罗宾原版对话(不影响好感/剧情)
- 每个建筑**当天只问一次**,第二天重置;节日/剧情对话优先放行

**费用**:加班费 = 建筑(或升级项)建造费 × 2(可配置 1.0~3.0)

## 配置(需 GenericModConfigMenu)

游戏内 ESC → 齿轮 → "罗宾加班"页:

- 自动弹窗询问(开/关)
- 右键罗宾补款(开/关)
- 加班费倍数(1.0~3.0,默认 2.0)
- 只在农场弹窗(默认开:矿洞/镇上不打断操作)

## 联机

主机弹窗时,客机玩家会收到 HUD 提示"主机正在考虑要不要让罗宾加班"(双方都需装本 mod)。

## 安装

1. 点右上角 **Code → Download ZIP** 下载本仓库
2. 解压后把 `RobinOvertime` 文件夹放进 `Stardew Valley\Mods\`(确认里面有 `RobinOvertime.dll` 和 `manifest.json`)
3. 需要 [SMAPI](https://smapi.io/)(4.0+) 和 [GenericModConfigMenu](https://www.nexusmods.com/stardewvalley/mods/5098)(可选,用于配置页)

## 兼容性

- 单人/联机(主机弹窗,客机收广播)
- 支持主农场 + 姜岛农场建筑
- 只处理罗宾(Builder=Robin)建造的建筑,不影响法师魔法建筑
- 状态存在建筑 modData,存档读档后行为一致
